# Security policy

Burnbird is in development and not running as a service yet. Once live, it reads the job details of the repositories
where its GitHub App is installed, so a security problem here is anything that could expose that data or let someone
see another account's data: a flaw in the code, a workflow or a configuration file.

## Reporting a problem

Use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a
vulnerability**. Please do not open a public issue for it. Include what you found, where, and how to reproduce it.

We answer every report within a week and tell you what we will do about it. We publish the details after the fix is
released.

## Supported versions

Only the latest commit on `main` is supported.
